# 设计与技术记录

## 第一版意图

固定、略带俯视的正交镜头；左岸形成弧线，水面留白；一只白天鹅成为视觉重心。以灰蓝暗部、暖白亮部和春日草绿建立统一色彩。画面的运动缓慢，涟漪比鸟更轻。

名称“半湾”是本工程的作品名，第一版没有采集或模拟真实地理数据。

## 渲染选择

- **形体**：天鹅由原创 Blender 脚本生成并导出 GLB；草岸、树、花草与石头在 Three.js 内生成。
- **材质**：以法线和光线点积得到亮度，用四种有意选定的颜色分层，边界保留小范围柔化。实例化及非均匀缩放物体使用相应的法线变换。
- **光影**：方向光阴影与人工配色组合，暮色同时改变光色和阴影方向。
- **水**：Three.js Reflector 提供镜像相机及反射纹理；原创片元着色器将反射混入湖色，再加入时间驱动噪声与轻微高光。
- **尾波**：每0.25秒记录尾部世界坐标，保留7秒，固定容量32点。每个波前向外扩散并衰减，旧波纹不会随鸟转弯而一起旋转。
- **动画**：按曲线弧长推进路程、以切线决定朝向，身体轻微浮动。背景页不推进可见动画；减少动态偏好默认暂停。
- **纸张感**：页面用内嵌 SVG 噪声和渐隐边缘形成纸面呈现；它不改变三维几何体，也不在导出的湖面 PNG 中。

## 实际参考与归属

1. [craftzdog / ghibli-style-shader](https://github.com/craftzdog/ghibli-style-shader)：参考其法线点积到离散调色板的风格思路。本工程的材质代码、调色板和几何体重新编写，没有复制 `trees.glb` 或整套工程。
2. [Cortiz / Stylized Components](https://github.com/cortiz2894/stylized-components)：调研草、水和 Painterly 的组件分工。本版没有复制其源码、GLB 或纹理，也没有启用其 Kuwahara 后期。
3. [Three.js Reflector](https://threejs.org/docs/pages/Reflector.html)：通过已安装的 Three.js addon 使用平面反射。Three.js 使用 MIT 许可，依赖包包含相应版权声明。
4. [Three.js Curve](https://threejs.org/docs/pages/Curve.html)：使用曲线弧长采样与切线作为游动基础。

白鸟、场景几何体、图标和页面美术均为本项目生成。没有使用 @notjignes 原作的图片、视频、模型或未公开源码，也不声称这是其作品的技术还原。

## 后续可以有针对性调整的地方

先评估白鸟的轮廓与画面比例、湖水的色相、树冠色块和整体疏密，再决定是否加入真实地点的岸线、独立头颈动作或更细致的草水交界。改变地点和鸟种应作为明确的设计迭代。
